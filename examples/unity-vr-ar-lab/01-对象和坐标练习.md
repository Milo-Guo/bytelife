# 练习一：对象、坐标和地形

在工程副本里操作，先另存场景，每次只改变一个因素。

## A. 分清资源模板与场景实例

1. 在 Project 中找到一个 Cube 或自建物体的 Prefab。
2. 拖入 Hierarchy 两次，分别放到 `(0, 0, 0)` 和 `(3, 0, 0)`。
3. 选中其中一个实例，改变它的位置。
4. 观察另一份是否改变，注意有没有执行 Apply。

预期：实例位置可以不同；模板是资源，两份实例是场景中的两个对象。删除一份场景实例，不会自动删除 Project 中的模板。

## B. 分清局部坐标与世界坐标

1. 创建空对象 Parent，Position `(10, 0, 0)`、Rotation `(0, 0, 0)`、Scale `(1, 1, 1)`。
2. 把一个 Cube 放到 Parent 下，Cube 的局部 Position 设为 `(0, 2, -4)`。
3. 在没有旋转和缩放时，理解它的世界位置是 `(10, 2, -4)`。
4. 把 Parent 的 Y 旋转改为 90°，观察 Cube 绕 Parent 改变位置。

预期：有旋转时，局部方向随父级转动，不能只把位置数字相加。

## C. 地形高低和涂色分别试一次

1. 选择练习 Terrain，在 Paint Texture 添加基础草地层，再添加沙地层。
2. 选沙地，在一小片区域刷色。
3. 切到 Raise or Lower Terrain，在同一区域抬高。
4. 切 Smooth Height，降低局部尖刺。
5. 使用 Ctrl+Z 撤回一次，观察回退的是哪一步。

预期：纹理和高度分别变化；刚创建的默认棋盘地形不等于出错。整地恢复会影响整张高度数据，做之前先备份。

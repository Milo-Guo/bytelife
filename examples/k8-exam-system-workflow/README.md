# K8 会考系统课程配套

这是根据 3 小时 35 分 36 秒录课和四份附件提示词重新编写的学习材料。保留课程阶段思路，修正路径、重复 AC 来源、外键概念和 SQL 执行边界。不是老师项目源码，不包含完整 47 功能正文、77 接口实现或 24 表 SQL，也不能直接启动 K8 系统。

教程：https://milo-guo.github.io/bytelife/articles/k8-exam-system-workflow/

## 怎样使用

1. 解压资料包，用 VS Code 的 File → Open Folder（文件 → 打开文件夹）打开。
2. 先读 `阶段核对表.md`。选当前阶段的 prompt，复制到自己的项目 `prompts` 目录，填写尖括号占位内容，Ctrl+S 保存。
3. 在 AI 工具中选对项目目录，新建或进入该阶段会话，发送填好的提示词。四份提示词需要分别使用，不要一次性全发。
4. 输出后在 VS Code 打开真实文档，核对路径、正文、版本、F/AC 和未决事项。
5. 已有项目只做增量修改，使用 `增量变更交接模板.md`。同一组文件只安排一个写入会话。

这些文件是文本模板，无应用运行命令，无依赖安装。检查示例中的 PowerShell 命令从你自己的项目根目录运行。成功标志是约定文档确实写入、内容和引用一致，未做的验证明确标“未执行”。没有老师源文件时不要把本包补充示例说成课堂完整结果。

## 文件

- `prompts/00-env-setup.prompt`：项目规则与目录约定。
- `prompts/01-requirement.prompt`：原始需求、稳定编号、唯一 AC 来源。
- `prompts/02a-architecture.prompt`：架构和接口契约，新增业务回需求。
- `prompts/02b-database.prompt`：SQL、结构说明及验证边界。
- `阶段核对表.md`：每阶段输入、输出、完成条件。
- `增量变更交接模板.md`：避免多会话互相覆盖。
- `功能到测试贯穿示例.md`：提交测验的 F、AC、接口、表、测试映射。
- `排错速查.md`：路径、编码、文件状态和验证问题。

课件中的“复合主键代替外键”、仅凭手机号或 openid 认定身份等表述不能照搬。修订模板把需要确认的决定留为待确认，不编造现成账号、真实密钥或实跑结果。所有执行范围仍以使用者当前明确指令为准。

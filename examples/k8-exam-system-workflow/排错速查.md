# 排错速查

| 问题 | 先检查 | 实际处理 |
| --- | --- | --- |
| 找不到需求文件 | 当前项目和真实 docs 路径 | 列目录，统一引用，别同时维护扁平和目录式两份 |
| 只看到空文件 | Length 与正文 | 先完成当前阶段，不把预建骨架当交付 |
| 改了 prompt 没变化 | 是否 Ctrl+S、是否发送当前内容 | 保存、发送、核对目标文档 |
| 会话中断 | Git diff、修改时间与实际内容 | 从已完成部分继续，不假设零写入 |
| 两会话写同一文档 | 各会话当前范围 | 停止并发，合并差异，单一写入者交接 |
| 新会话不知道前情 | 是否读规则和上游文件 | 提供路径、版本、范围，不靠聊天标题推断 |
| AC 多份冲突 | 哪份含独有内容 | 备份/比对，合并到唯一需求来源，修引用 |
| 检查 PASS 仍有缺口 | 检查器检查了哪些内容 | 审业务决定与边界，不按 PASS 数决定完成 |
| 检查 FAIL，原文似乎正确 | 失败规则、缩进解析、章节范围和统计条件 | 先复现误判再修检查器，不能随意删规则变绿 |
| 改好的文档又恢复旧内容 | 是否为生成产物、源是否同步 | 修改实际源，重新生成并比较差异，保护人工进度 |
| 已有目录却提示未登记项目 | 工作区、插件登记与看板是否同一对象 | 核对目录关联和插件状态，不重复创建同一目录 |
| NX 中的部署要求没落实 | 是本期排除，还是移交架构 | 保留原约束，指定接收文档并核对落地状态 |
| Q 编号跳号或默认值像已确认 | 展示的是否只是问题子集、是否有明确回答 | 按原编号加问题短名回答；建议保留待确认状态 |
| 错题移出后统计变少 | 是否把移出误做删行、混淆两种计数 | 区分当前列表、累计错误次数与连续答对次数 |
| 反馈没有回复入口 | 本期是否只做状态处理 | 先读范围；本课不做管理员回复，不能自行补客服系统 |
| 黄色框很多 | Unicode 高亮提示 | 调整高亮；中文可读时不必改编码 |
| 空白方框 | 复选框字符、字体支持 | 识别字符，再换字体或简单标记 |
| 中文错误或出现替代字符 | 解码和原始字节是否已损坏 | 先备份、尝试正确编码重新打开；已损坏从历史恢复 |
| SQL 没有实际建表 | 是否只写了 schema.sql | 看执行记录；需要实跑时明确隔离目标与范围 |
| 验证版本不同 | SELECT VERSION/实际镜像版本记录 | 记实际结果，再补目标版本，不混写 |
| 表数一样但字段变了 | 需求版本与结构差异 | 对比列、约束、索引与 F 覆盖，不能只数表 |
| 只有登录标识没有验证 | openid/手机号是否被当成凭证 | 服务端核验可信凭证，补绑定冲突与旧会话撤销 |

教程最后时间轴覆盖全片。发现本包与自己的项目约定冲突时，先确认实际规则和已拍板业务决定，再做最小修订；不要为套模板覆盖已有用户工作。

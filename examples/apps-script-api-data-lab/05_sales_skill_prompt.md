# 销售汇总技能的学习模板

把下面内容作为技能指令保存。先将占位文字换成自己有权访问的表格链接。

```text
每次调用时，重新读取【填写自己的Google Sheets链接】中的最新数据。
先报告读取到的文件名、工作表名、列名、有效记录数和日期范围。
根据本次指令按商品、日期或负责人汇总，输出标题、表格和总计。
不要把历史聊天中的结果当作最新数据。

如果有数量列，销售额按单价乘数量计算。
如果只有日期、商品名和单价，先说明“按一行代表一次销售记录，合计单价”的口径。
不能从现有字段确认一行就是一件商品时，明确这是计算假设。
负责人等必要列缺失时，指出缺少的列，不编造分组结果。
访问失败时，说明失败，不声称读取成功；提示检查当前账号、连接权限和共享设置。
汇总完成后检查各分组合计是否等于总计。
```

先测试“读取表头和前3行”，再测试“全期间商品别汇总”。
这是一段可复用的任务规则；能否读取表格仍取决于账号、连接和共享权限。
